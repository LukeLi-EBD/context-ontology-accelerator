## 1. 目标复述

第一原则是**一个 UI、一个入口、一套契约、一套功能点**：界面只有 `packages/web-app`，`platform-core/web` 的页面全部消失且能力逐条落位；所有能力只走 COA 的三套契约（`ControlPlaneService` / `DataLayerService` / `OntologyService`），**对外只有一个网关、一个 base URL**，`platform-core/api.py` 的 **135 个端点**（2026-11-10 实扫；旧记 137）不得作为第二组对外路由并存，契约缺口用新增 Smithy operation 补；同一能力只有一个 owner operation、一个 UI 路由、一个数据源，不许两套说法、两套指标口径、两套健康检查。完成定义是 D1 一条命令起全栈且无 AWS 凭证、D2 运行期无 AWS 出站、D3 契约可调且返回真实数据、D4 业务代码不依赖具体实现、D5 配置矩阵可查可混搭、D6 特性清单逐项可用、D7 单机可跑、**D8 单一 UI 与单一入口**（`platform-core` 目录不存在、`grep platform_core` 归零、对外只经一个网关 / 一个 base URL、8080/8082 无监听）。八条缺一不算完成。

## 1. 目标与边界

### 1.1 coa-x 是什么

- 在 COA 现有代码上二开，不新起并列系统。
- 把依赖 AWS 的组件换成本地实现：Oxigraph/Fuseki、pgvector、PostgreSQL、BGE-M3、本地 OpenAI 兼容 LLM。
- 整合 platform-core 已有能力，用端口 + 组合根收口，而不是在各服务里散落 `if provider == ...`。
- coa-gateway 只作载体/实验台，不是交付物；网关不聚合、不持有领域状态。

### 1.2 明确不做什么

| 不做 | 原因 |
|---|---|
| 不重写 COA 业务逻辑 | 只换依赖实现，保留既有行为 |
| 不重造 platform-core 已有组件 | 能复用就复用，端口只做薄壳 |
| 不做生产切换、IaC、多租户鉴权 | 本阶段是本机可运行，不是上线 |
| 不承诺未验证组合 | 没真跑过的 provider 不写成「可用」 |
| 不在网关里做聚合/编排 | 避免长出新单体 |
| 不做性能优化 | 当前只记录延迟，不调参 |

### 3.2 四种显式拒绝

| 错误码 | 触发条件 | 行为 |
|---|---|---|
| `config_missing` | 配置键缺失或为空 | 启动即抛，不选默认 provider |
| `provider_unknown` | 值不在该接口的 provider 列表 | 启动即抛，列出 allowed |
| `provider_not_available` | provider 合法但 `implemented=False` | 启动即抛，不偷换实现 |

### 5.2 统一语言 8 条裁定

| # | 术语 | 裁定 | 代码落地 |
|---|---|---|---|
| 1 | Metric | 只指指标**定义**，不指数值 | `MetricIndexPort` / `MetricGraph` 已用；旧代码仍偶见 metric 指数值 |
| 2 | Observation | 只指指标观测值；执行统计不能叫 Observation | DTO 有别名；旧字段未全收口 |
| 3 | ExecutionFeedback | 执行反馈统一叫这个；不叫 observation | **未落地**，代码中无此类 |
| 4 | ontology version | 只由 ontology-engine 的 version 定义，其他包不得自造 | 部分；本体路由尚未挂全 |
| 5 | Namespace | 只指租户隔离边界，不指 RDF 命名图/KS 命名空间 | 部分；图侧仍用 namespace 拼 URI 前缀 |
| 6 | Entity | 只指图主语（IRI 节点），不指表行/文档块 | 部分 |

| 8 | Ontology vs Graph | Ontology 只指 schema（T-Box）；Graph 指实例数据（A-Box） | 包边界已分开；运行时数据面未闭环 |

### 5.3 落地程度（如实）

- 已落：7 个上下文的包边界、端口 DTO、术语表、8 条裁定。

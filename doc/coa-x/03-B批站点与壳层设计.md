|---|---|---|
| `converse` | **能** | 平台侧 `complete_json` / `BedrockClient.invoke` 都是同步阻塞调用，`run_in_executor` 即可；需把返回 dict 映射成 `ConverseResult` |

另有一处行为差异需记录：平台 `LlmClient` 没有 guardrail，`ConverseResult.guardrail_outcome` 只能填 `NONE`。

## 6. 壳层设计

### 6.1 通用同步→异步壳（新文件 `local-providers/src/coa_local_providers/shells/async_bridge.py`）

```python
class SyncToAsyncShell:
    def __init__(self, inner, *, max_workers: int = 8, provider: str = "unknown") -> None:
        self._inner = inner
        self._provider = provider
        self._pool = ThreadPoolExecutor(max_workers=max_workers, thread_name_prefix=f"coa-{provider}")

    async def _call(self, fn, /, *args, timeout_s: float | None = None, **kwargs):
        loop = asyncio.get_running_loop()
        future = loop.run_in_executor(self._pool, functools.partial(fn, *args, **kwargs))
        try:
            if timeout_s is None:
                return await future
            return await asyncio.wait_for(future, timeout_s)
        except asyncio.CancelledError:
            future.cancel()          # 只阻止结果回传；线程本身无法中断
            raise                    # 绝不映射成 PortError
        except (asyncio.TimeoutError, TimeoutError) as exc:
            raise PortError(PortErrorCode.TIMEOUT, "sync call timed out", provider=self._provider) from exc
        except Exception as exc:
            raise to_port_error(exc, provider=self._provider) from exc
```

**取消语义（必须写进 docstring）**：`run_in_executor` 的线程无法被抢占。外层 `CancelledError` 触发时，壳取消 asyncio Future 并立即上抛，但底层 HTTP 调用仍会跑完；壳**不承诺"取消即停止远端请求"**，只承诺不吞异常、不在取消后写共享状态。池大小有界（默认 8），进程退出时 `shutdown(cancel_futures=True)`。

**超时语义**：Graph / Vector / LLM 端口本身没有 timeout 参数，壳不发明业务超时，只把 inner 自己抛的超时映射为 `PortError.timeout`；`QueryExecutor.execute` 自带 `timeout_seconds`，壳用它作为 `wait_for` 上限并透传给 inner。LLM 额外引入 `COA_LLM_TIMEOUT_S`（默认 60s），因为平台 `complete_json` 的重试叠加后可能长时间不返回。

**错误码映射**：

| 来源 | 映射 |
|---|---|
| botocore `ClientError` / `BotoCoreError` | 复用 `coa_local_providers.aws.errors.to_port_error`（7 码，`AccessDenied` 归 `internal`） |
| `platform_core` 领域异常 | 复用 `shells/errors.py::PLATFORM_TO_PORT_CODE`，未知归 `internal` |
| `asyncio.TimeoutError` / `TimeoutError` | `timeout` |
| `asyncio.CancelledError` | 原样上抛，不映射 |
| 其他 `Exception` | `internal`，消息脱敏沿用 `drop=("value",)` |

class PlatformLLMShell(SyncToAsyncShell):
    async def converse(self, *, system, messages, tools=None, max_tokens=..., temperature=..., guardrail_id=None, **kw) -> ConverseResult:
        payload = {"system": system, "user": _flatten(messages)}
        raw = await self._call(self._inner.complete_json, timeout_s=self._timeout,
                               **payload)                 # 或 inner.invoke(system, prompt)
        return ConverseResult(text=raw[...], usage=..., guardrail_outcome="NONE")

    def converse_stream(self, *args, **kwargs) -> AsyncIterator[str]:

        raise PortError(PortErrorCode.UNSUPPORTED, "embedding belongs to EmbeddingPort", provider="openai-compatible")

        return {"ok": bool(self._inner.configured), "backend": "openai-compatible"}

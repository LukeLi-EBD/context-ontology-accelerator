#### (1) 新增本地实现 `GraphOntologyLookup`

建议放在 `packages/metric-service/src/coa_metrics/ontology_lookup_graph.py`（**不要**放 `packages/local-providers`，该目录另一会话在改）。

```python
"""OntologyLookup over the local Oxigraph graph (sync, read-only)."""

from __future__ import annotations

from coa_metrics.lookups import OntologyLookup


class GraphOntologyLookup(OntologyLookup):
    # 与 NeptuneOntologyLookup 相同的输入白名单，直接复用其正则行为
    def __init__(self, store) -> None:      # store: platform_core OxigraphHttpStore（同步）
        self._store = store

    def class_exists(self, class_uri: str, namespace: str) -> bool:
        if not isinstance(class_uri, str) or not _SAFE_CONCEPT_RE.match(class_uri):
            return False
        query = (
            "ASK { GRAPH ?g { <%s> a <http://www.w3.org/2002/07/owl#Class> . } "
            'FILTER(STRSTARTS(STR(?g), "%s/%s/")) }'
        ) % (class_uri, _graph_base(), namespace)
        try:
            return bool(self._store.ask(query))
        except Exception:
            return False  # 与 NeptuneOntologyLookup 一致：失败放行
```

要点：
- 必须**同步**。`JsonDataSourceLookup` 与 `NeptuneOntologyLookup` 都是同步；端口若声明 async，消费点（同步 Lambda）还得再套一层事件循环。
- 用 `platform_core.adapters.graph_oxigraph.OxigraphHttpStore`（同步），不要用 `local-providers/graph_oxigraph.py` 的 `OxigraphGraphClient`（async，见该文件 `async def query`）。
- `_graph_base()` 复用 `neptune_client._resolve_graph_base`，保证图 IRI 前缀与写侧一致。

## 4. 起服务：两个方案

`metric-service` 现在是 Lambda handler，合并入口是 `packages/metric-service/src/coa_metrics/api/metric_api_handler.py:42-77`，按 `httpMethod` + `resource.endswith(...)` + `pathParameters` 分发。事件面很小（实测 grep）：`httpMethod`、`resource`、`pathParameters{namespaceId,name,jobId}`、`queryStringParameters`、`multiValueQueryStringParameters`、`body`、`requestContext.authorizer`。

### 4.1 方案 A：ASGI 适配层 + uvicorn（推荐）

新增一个文件（建议 `packages/metric-service/src/coa_metrics/local_asgi.py`，约 45 行）：

```python
"""Local ASGI bridge: translate HTTP → API Gateway proxy event → metric_api_handler."""

from fastapi import FastAPI, Request
from fastapi.responses import Response

from coa_metrics.api.metric_api_handler import handler

app = FastAPI()


@app.api_route("/{full_path:path}", methods=["GET", "POST", "PUT", "DELETE"])
async def dispatch(request: Request, full_path: str):
    path = "/" + full_path
    parts = [p for p in path.split("/") if p]
    params: dict[str, str] = {}
    if len(parts) >= 2 and parts[0] == "namespaces":
        params["namespaceId"] = parts[1]
    if len(parts) >= 4 and parts[2] == "metrics":
        params["name"] = parts[3]
    if len(parts) >= 5 and parts[3] == "import-jobs":
        params["jobId"] = parts[4]

    raw = await request.body()
    event = {
        "httpMethod": request.method,
        "resource": path,
        "path": path,
        "pathParameters": params or None,
        "queryStringParameters": dict(request.query_params) or None,
        "multiValueQueryStringParameters": {
            k: request.query_params.getlist(k) for k in request.query_params
        } or None,
        "headers": dict(request.headers),
        "body": raw.decode("utf-8") if raw else None,
        "isBase64Encoded": False,
        "requestContext": {"authorizer": {"principalId": "local-dev"}},
    }
    out = handler(event, None)
    return Response(
        content=out.get("body", ""),
        status_code=int(out.get("statusCode", 200)),
        headers=out.get("headers") or {},
    )
```

- 依赖：`uvicorn 0.48.0`（**已离线装入 `.venv-coa-local`**）、`fastapi`/`starlette`（原已装）。新增下载 0。
- `requestContext.authorizer.principalId` 必须给一个值：不给则 `get_caller_identity` 返回 `"unknown"`，带 `clientToken` 的 create 会 fail-closed 到 503（`idempotency.py` 文档字符串第 15-17 行）。
- 代价：路由解析规则与 API Gateway 模板要维护一致（目前只有 8 条路由，`metric_api_handler.py:6-14` 已列全）；响应头直接透传；不做 CORS 之外的任何加工。

### 4.2 方案 B：stdlib `ThreadingHTTPServer`（0 新依赖）

沿用 `packages/vkg/translate-server.py` 的形态（`http.server` + `ThreadingMixIn`），在一个 `do_GET`/`do_POST` 里构造同样的 event 再调 `handler`。

- 代价：手写 body 读取、header 解析、并发与超时；没有 `/docs`、没有 ASGI 生态；代码量比方案 A 多，且和 vkg 一样要自己维护。
- 收益：不依赖 `uvicorn`/`fastapi`（但两者现在都已在 venv 里，收益不成立）。

### 4.3 方案 C：Lambda RIE（排除）

需要 `aws-lambda-rie` 二进制或镜像，本机 `docker images` 未见、网速 27–35 KB/s 下不可行；**未验证**。

### 4.4 对比

| 维度 | A · ASGI + uvicorn | B · stdlib HTTP | C · Lambda RIE |
|---|---|---|---|
| 新增依赖 | 0（已装） | 0 | 二进制/镜像（要下载） |
| 代码量 | ~45 行 | ~90 行 | 0 行（但要镜像） |
| 与线上事件形状一致性 | 高（显式构造 event） | 高（同一套构造） | 最高（真 RIE） |

| 本机可行性 | ✅ 已具备 | ✅ 已具备 | ❌ 未验证，大概率不可行 |

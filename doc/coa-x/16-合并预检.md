## 5. 台账与排期的合并口径（重点）

### 5.1 唯一的恒等式

`143 = 已落位 + 部分落位 + 未落位`，`部分落位` 恒为 3。合并后必须满足 **117 + 3 + 23 = 143**。

### 5.2 数字怎么加

|---|---|---|---|---|
| C 审批队列 | 12 / 0 / 5 | **17 / 0 / 0** | 未动 | 17 / 0 / 0 |
| E 检索与问答 | 3 / 0 / 1 | 未动 | **4 / 0 / 0** | 4 / 0 / 0 |

> 合并后实测（2026-11-10）：`07-研发台账.md` 终态为 **117 / 3 / 23**，与本表一致（合并时一度误记 112/3/28，已按分组行相加纠正）。**此表是账面数，实际以合并后台账为准**；后续再合 P4 等分支，不要直接引用本行。

### 5.3 具体怎么落

1. **表格行**：C 用主线的 17；E / F / J 用 p10-p11 的 4 / 7 / 12；合计写 117 / 3 / 23。
2. **「已落位 N 条清单」那一行**：写 117（两边都是从 106 往上加，106+5+6）。
3. **分组清单**：C 组那段用主线的 17 条版本（新增 F31 / F33 / F34 / F40 / F41）；E / F / J 三段用 p10-p11 的版本。四段互不重叠，直接拼。

   - 中间那两个数（111、112）保留，作为历史轮次值，**不能**拿它们当文件里的「当前值」。

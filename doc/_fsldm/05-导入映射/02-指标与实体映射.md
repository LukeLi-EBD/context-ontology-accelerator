# 02 · 指标与实体映射（36 条可用指标）

> 来源：`_fsldm/02-导入验证/S14-阶段一-报告.md` §2.2（原样转录，未改判定）。判定口径见该报告 §2.1：
> `有` = 主事实实体与所需维度实体均在已建模清单内；`部分` = 主实体或关键维度/支撑实体缺失但有邻近实体替代；`无` = 主事实实体完全缺失。
> **本表只回答“实体在不在”，不回答“数值对不对”；不含任何业务结论。**

## 2. 与平台本体类的落点

| 平台侧 | 对应 FS-LDM | 说明 |
| --- | --- | --- |
| `urn:fsldm:*` 命名图（T-Box） | 合并 TTL 全量 | 平台不另起命名体系；导入后类 IRI 原样保留（`https://w3id.org/fsldm/<module>#<Class>` 经 `fsldm:` 前缀简写） |
| A-Box 事实图 | `agmt:*` / `party:*` / `evt:*` 等实例 | 由 S4 抽取/审批写入，不直接复用 FS-LDM 实例数据 |
| 期次事实实体 | `fsldm:InsurancePaymentRecord`、`fsldm:LoanInstallmentPlan` | S14-H-04 新增；`subClassOf BusinessEntity, TimeBound`；对应 PG 表 `platform.ins_payment_record`、`platform.loan_installment_plan` |
| 指标定义 | `fsldm:Metric`（骨架类） | 平台 `platform.metric_definition` 独立建表，不内嵌到本体 |

## 3. 已知缺口

1. **capital（资本/一级资本净额）无类**：集中度与大额风险暴露类指标的分母只能外置参数表。
2. **费用/准备金/退保金无专用类**：`fin` 只有总账科目，不足以直接驱动综合成本率、未决准备金、退保率。
3. **保单状态历史不足**：S14-H-04 用期次快照替代，失效/复效/犹豫期撤单的细粒度状态码仍缺。
4. **表外/衍生/缓释后的风险暴露未落实体**：`FinanceExposureAgreement` 只覆盖表内。
5. **字段级映射未展开**：本文件只到“类”粒度，属性级映射见 `02-指标与实体映射.md` §3 的字段缺口汇总。

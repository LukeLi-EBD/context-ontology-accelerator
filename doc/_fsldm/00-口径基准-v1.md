## 1. 来源优先级与证据分级

### 1.1 来源优先级（高 → 低）

| 优先级 | 来源类型 | 代表 | 使用规则 |
|---|---|---|---|
| P1 | 强制监管 | 法律、部门规章、监管规范性文件、监管报表/偿付能力报告列报要求 | 主口径只能取 P1，且必须能指到条款 |
| P2 | 行业惯例 | 行业协会评价、国家标准（推荐性）、行业通行分析做法 | P1 缺失时可用，必须标注“行业惯例” |
| P3 | 厂商/咨询实践 | Dataphin/OneData 文档、FS-LDM 白皮书、CRM/SaaS 厂商、咨询机构 | 只用于方法论与结构，不用于监管口径结论 |

规则：同一指标多来源冲突时，取最高优先级为主口径，其余降为“变体”；不得把 P3 包装成 P1。

### 1.2 证据分级

| 等级 | 定义 | 本基准中的典型对象 |
|---|---|---|
| **A** | 现行有效法规/规章原文（含现行监管规范性文件、监管报表列报条文） | 《贷款通则》、《商业银行金融资产风险分类办法》（2023）、《商业银行风险监管核心指标（试行）》、《商业银行贷款损失准备管理办法》（2011）、《商业银行法》、《大额风险暴露管理办法》、《偿付能力监管规则第 18 号》、《保险公司偿付能力管理规定》（2021）、《非寿险业务准备金管理办法》（2021）、银保监办发〔2021〕7 号、保监发〔2015〕27 号 |
| **B** | 已废止或被替代 | 《贷款风险分类指引》（银监发〔2007〕54 号，2023 办法过渡期已结束）、《保险公司偿付能力额度及监管指标管理规定》（保监会令 2003 年第 1 号）中的旧指标公式 |
| **C** | 行业/协会/企业披露 | 中国保险行业协会评价指标、GB/T 36687—2018、财政部绩效评价指标体系、银行年报/官网披露、阿里云 Dataphin 官方文档（OneData 规则）、Teradata FS-LDM 白皮书、学术/厂商 RFM 与留存资料 |
| **D** | 二手或未核实；**不得作为计算基准** | 银监发〔2018〕7 号媒体转述、M0–M6 分桶、部分还款/最低还款判定、IFRS 9 B5.5.18（30 天）、BCBS 原句未逐字核对、首逾率/催收回收率等无权威定义的管理指标 |

### 1.3 判定规则（强制）

1. 每条结论只挂一个**主等级**；多来源时按 1.1 取最高，低等级来源进“变体/备注”。
2. “已核实”只表示调研时打开了原文，**不等于 A**；只有现行法规/规章原文才是 A。
3. C 文件自己的 A/B/C 分级（阿里云官方文档=A）在本基准中**降为 C**：企业官方文档不是法规规章，不因“官方”升格。
4. 取不到原文的，一律 D，并在 §6 登记缺口；不得用“行业通行理解”替代条文。
5. 旧规原文保留为 B 级历史版本，不删除、不覆盖；新旧口径数值不可直接比较。
6. **“状态=可用”的必要条件是存在至少 1 条 A 级或 2 条相互独立的 C 级来源；仅 D 级一律为“仅定义”。** D 级指标不得作为计算基准。

### 1.4 三份调研的分级换算

| 调研原文标注 | 本基准等级 | 说明 |
|---|---|---|
| A 文件“已核实”+ 现行法规/规章 | A | 如 2023 分类办法、核心指标、2011 拨备办法 |
| A 文件“已核实”+ 2007 指引 / 2003 规定 | B | 已被替代或过渡期结束 |
| A 文件“部分核实”/“未找到权威原文” | C 或 D | 有官方邻近来源取 C；仅行业/媒体取 D |
| B 文件“已核实”+ 规则 18 / 2021 规章 | A | 以条文和公式为准 |
| B 文件“已核实”+ 2003 规定 | B | 旧监管指标 |
| B 文件“部分核实”的协会/国标/公司披露 | C | 行业/协会/企业披露 |
| B 文件“未核实” | D | 实收保费、报案率、渠道费用率、RFM 无交易 R 等 |
| C 文件 A 级（Dataphin 帮助中心） | C | 方法论来源，不是监管口径 |

## 2. 指标卡结构（四元组）

### 2.1 指标卡字段

| 字段 | 必填 | 说明 | 借用来源 |
|---|---|---|---|
| 指标 ID | 是 | 稳定不变；改名不改 ID | C §5.3（一指标一稳定 ID） |
| 原子指标（业务过程 + 度量） | 是 | 一个业务过程 + 一个度量 + 聚合逻辑；只挂一张事实表 | C §3.1 |
| 业务限定 | 是（无则写“无”） | 类似 WHERE，**不含时间区间**，每条可判定 | C §3.1 |
| 统计周期 | 是 | 日/月/季/年/时点 | C §3.1 |
| 统计粒度 | 是 | GROUP BY 的维度或维度组合 | C §3.1 |
| 口径来源 / 证据等级 | 是 | 法规名 + 条款 + A/B/C/D | 本基准 §1 |
| 公式 | 是 | 可复算表达式；比率型写清分子分母 | C §3.1 |
| 边界规则 | 是 | 含/不含、去重、时点、剔除项 | C §7.1 第 7 条 |
| 数据字段需求 | 是 | 段级字段清单，不写物理表名 | C §3.2 |
| 变体（同义不同名） | 是（无则写“无”） | 同名不同义必须另立 ID | 本基准 §3 |
| 状态 | 是 | 可用 / 仅定义 / 不可计算 | 本基准 §5 |
| 可累加性 | 是 | 可加/半可加/不可加；比率一律不可加 | C §7.1 第 3 条 |
| 版本 / 生效区间 | 是 | 口径变更即新版本，保留旧原文 | C §5.2 |

签发规则：四元组（原子指标、业务限定、统计周期、统计粒度）缺一项不签发；缺数据字段可签发为“仅定义”，但不得标“可用”。

## 7. 后续动作（只列计划，不执行）

### 7.1 字段级映射（FS-LDM 实体/属性 → 指标所需字段）

1. 只对状态“可用/仅定义”的 77 条做映射；“不可计算”的 2 条只记录缺口。
2. 映射行格式：`指标ID | 所需字段（段级） | 候选 FS-LDM 实体.属性 | 覆盖状态（有/推断/缺） | 备注`。
3. 候选实体按域取：ACCOUNT/AGREEMENT、ACCOUNT COLLECTION STATUS、PARTY/PARTY GROUP、APPLICATION、DEFAULT RECOVERY、EVENT/FINANCIAL EVENT/ACCOUNT EVENT、Financial Plan、bank-capital-history、INSURANCE AGREEMENT/POLICY、CLAIM/CLAIM COVERAGE、REINSURANCE AGREEMENT、SECURITY ASSET/ASSET VALUE HIST、MOTOR VEHICLE。
4. 属性级必须先补 XSD 类型：现有 FS-LDM 只有属性名+描述，无数据类型/长度/主键（fsldm-inventory §7）；日期与金额类型推错会直接导致 DPD、MOB、迁徙率算术失效。
5. 产出物：字段映射表 + “不可映射清单”（每条写缺实体/字段，回填 §5）。

### 7.2 合成探针数据设计

依据：FS-LDM 目录内 0 个 CSV/Parquet/XLSX/数据库导出，无明细数据（fsldm-inventory §5），必须自备合成数据才能做数值验证。

1. 最小字段集：账户号、客户号、产品/贷款类型、放款日、到期日、首期应还款日、每期应还/实还、未偿本金、观察日快照（按月）、五级分类、核销金额/日期；保险侧补保单号、险种、承保日、缴费期次、实收保费、退保日/退保金、赔案号、报案/立案/结案日、估损/已决金额、准备金期初期末。
2. 边界用例必须覆盖：90 天 vs 91 天（“超过”语义）、7 天技术性豁免、还款当日 DPD=0、部分还款两套假设、重组观察期 1 年/2 个还款期、再次重组、13/25 个月继续率（失效/复效/犹豫期撤单）、退保犹豫期、综合赔付率再保前后。
3. 每个用例带“预期结果”与“口径版本号”，用于回归；合成数据不得冒充真实业务数据。

### 7.3 三轮验证

| 轮次 | 验证什么 | 通过标准 | 不通过的处理 |
|---|---|---|---|
| R1 结构验证 | 口径能否在 FS-LDM 本体中放下：四元组齐全、实体/属性可达 | 每条“可用/仅定义”都有映射行；四元组缺项 0 | 补映射或降为“仅定义”，不回填虚假字段 |
| R2 口径计算验证 | 用合成数据按公式复算，边界用例全部命中预期 | 边界用例通过率 100%；比率分子分母可逐笔追溯 | 修口径边界或修公式登记，不调整预期值迁就结果 |
| R3 版本与治理验证 | 口径变更生成新版本、旧原文保留、只下线不删除、同名不同义无重复 ID | ID 唯一；旧版本可查；下线指标仍有引用记录 | 重建版本链，禁止覆盖式编辑 |

三轮均只做口径与结构验证，不做真实业务数值结论；R2 结论必须标注“合成数据，不代表真实组合表现”。

### 1.1 `D:\FS-LDM` 内没有监管原文

- 结论：本任务中“监管原文”只能来自研究文档 `A-银行信贷监管口径.md` / `B-保险与客户经营口径.md` 的**条款原文摘录**。下文证据列统一写作：`法规名 + 条款号（转引 A/B §x Lxxx）`。凡研究文档未收录原文的，标 `EVIDENCE_MISSING`，不编条款。

### 1.2 证据等级与 v2 判定口径

- 沿用 v1 §1.2 的 A/B/C/D。A 级要求现行法规/规章原文；B 级为已废止/被替代；C 级为行业/协会/企业披露；D 级不得作为计算基准。
- v2 新增判定（写入 `00-口径基准-v2.md` §1）：
  1. **可用** = 四元组（原子指标、业务限定、统计周期、统计粒度）齐全 + 公式可复算 + 证据 A（或 ≥2 条独立 C）+ 分子分母可在本体已有实体/属性/SKOS 概念上落地（允许“属性待建”，不允许“关键实体缺”）。
  2. **仅定义** = 口径已确定但四元组缺项、或证据仅 B/C 单源、或关键字段未落地。
  3. **证据缺失** = 连权威口径原文都取不到（D 级），分子/分母/周期/粒度无法按条文写死。该档从 v1 的“仅定义†”中拆出，不是新增指标。
  4. **不可计算** = 缺整个关键实体且模型无对等物。
- 落地判据只认**已有**术语：`fsldm:Metric`（含 `metricType` + `metricOf` + `observationDate`）、`fsldm:Classification`（含 `classifies` + `inScheme` + `hasClassValue` + `validFrom/validTo`）及 `fsldm-codes.ttl` 中已存在的 SKOS 概念。需要新增 SKOS 概念的，写入 `07-候选术语/`，**不据此升级**。

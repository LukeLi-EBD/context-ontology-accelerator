# 口径基准 v3

- 版本：v3.0（2026-11-06）
- 基线：`00-口径基准-v2.md`（v2 文件不改、不覆盖；本文件继承 v2 全部 79 条条目、证据等级与四档状态）
- 变更：只新增 `evidenceBasis` 与 `publishable` 两列（另在判定列内标注 `inference` / `missing` / `formulaDisabled` 派生值），**不重写** v2 四档状态。
- 依据：`08-证据缺口补全-台账.md`（25 条 D 级处置）+ v2 §2 全表。

## 1. 新增列定义

| 列 | 取值 | 判据 |
|---|---|---|
| `evidenceBasis` | `regulatory` | v2 证据等级 A/B，研究稿可定位监管文件与条款（注：尚未与监管 PDF 逐字核验，见 v2 §1.1） |
|  | `industry` | 证据等级 C（学术/厂商/行业）或台账“部分”（仅行业通行公式 / 原文存疑） |
|  | `none` | 台账 `no-source`：无监管原文且无成文行业公式 |
| `publishable` | `true` | `regulatory` 且有原文支撑，可对外发布/报送 |
|  | `false` | `industry` / `none` / 不可计算：仅内部出数或不出数；对外返回 `E_METRIC_NOT_PUBLISHABLE` |

出数约束（与平台护栏一致）：
1. `evidenceBasis=regulatory` 且 `publishable=true`：对外/内部均正常出数，`source=REGULATORY`、`inference=false`。
2. `evidenceBasis=industry`：仅内部出数，必须带 `source=INDUSTRY`、`inference=true`、`evidenceStatus=EVIDENCE_MISSING|INDUSTRY_ONLY`；对外拒绝。
3. `evidenceBasis=none`：任何路径都不出数，`E_METRIC_NOT_PUBLISHABLE` + `missing=source`。
4. `formulaDisabled=true`（FIN-INS-022/023）：公式停用，任何路径都不出数。
5. `FIN-INS-029/030`：`regulatory` 但不可计算，`publishable=false` + `missing=entity`。

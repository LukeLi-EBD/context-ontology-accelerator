### 1.2 高风险待实测：推理输入图指向空 A-Box

已确认的事实（本次只读实测）：

| 项 | 值 |
| --- | --- |
| `/status.reasoning.aboxGraphs` | `["urn:platform:graph:abox:main"]` |
| `urn:platform:graph:abox:main` 三元组数 | **0** |
| `urn:platform:graph:abox:synthetic` 三元组数 | **304,919** |
| 当前 inferred 三元组数 | **28** |
| 平台 A-Box 规模（52/47） | 60,420 实例 / 304,919 三元组 |

**为什么是高风险**：`abox_graphs` 决定物化的输入图。如果物化与一致性门禁只读 `abox:main`，则 30 万条 A-Box 事实很可能从未参与推理，一致性门禁也一直在对空图“空过”。当前 inferred 28 与“T-Box 自身闭包”量级相符，不能证明 A-Box 参与过。

**不写死结论**。需要三组实测（另有专线在跑）：

| 组 | 输入 | 观测 | 判定 |
| --- | --- | --- | --- |
| A | `abox:main`（空） | inferred 数、耗时、内存、一致性 verdict | 复现“空图空过” |
| B | `abox:synthetic`（304,919） | 同上，并记录物化预算（时长/峰值） | 证明 A-Box 参与后的真实输出与代价 |
| C | 当前库 | inferred 28、门禁 verdict、输入图指纹 | 判断当前库属于 A 还是 B |

**验收口径**：A/B 的 inferred 数与 verdict 必须有可解释差异；C 必须能对上 A 或 B 之一。若 C 对不上任何一组，按“配置/物化未生效”处理。文档只记录方法与已知数字，不把“从未参与推理”作为结论。

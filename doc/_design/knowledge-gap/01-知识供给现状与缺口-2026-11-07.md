## 0. 阶段结论

1. **本体覆盖的是"实体 + 字段"知识，不是"规则"知识。** 156 个类、129 个属性里，时效制度 **0 条**、流程制度 **0 条**、政策约束 **0 条**、阈值制度 **2 条**（且只是产品特性的浮动区间，不是政策阈值）。G05/G06 的缺口不是"某条数据没填"，而是**整类知识不存在**。
2. **拒答是正确的；错的是 golden 期望。** G05/G06 在 golden set 里的通过条件是"不拒答 + 有 ontology-version 引用"，而问题本身要求一个本体不可能有的数值/流程。当前覆盖度实测：G05 `5/13 = 0.3846`，G06 `3/16 = 0.1875`，门限 `0.6`。
3. **G05 可以被"骨架知识"解冻，但不等于答对。** 门禁中性 seed 里给新类写 `rdfs:label "历史记录保留"@zh`，覆盖度从 `0.3846` 升到 `0.8462`（过线），但具体月数仍然是空的——**不能用它来宣称 G05 修好了**。
4. **G06 无法靠合法术语过线。** 能过线的唯一词面是题面片段 `"价值发生巨大变化"`（`11/16 = 0.6875`）；业务自然词 `"价值重估"`/`"处置流程"`/`"押品处置"`/`"巨大变化"` 全都不改变 `0.1875` 或只到 `0.4375`。把题面片段做成 altLabel 属于造词，不做。
5. **与 A 主尺子的冲突是硬冲突**：要让新知识进入检索词表，必须给新类挂 `term:termBatch` 并加带语言标签的 `altLabel`，这会把锚点类 `15 → 17`、tagged altLabel `18 → 20`，直接让 `term_eval.py` 的两条断言失败，并把 O-05 的 `aliasRatio` 从 `1.0` 推到 `1.111`。以 A 为准：**该文件只作提案，不启用。**

## 1. 现状量化（可核对数字）

### 1.1 口径

- 类：`?s a owl:Class`。
- 属性：`owl:ObjectProperty` + `owl:DatatypeProperty`。
- 语义分类：**只看 `rdfs:label` + IRI 本地名**（不把 `rdfs:comment` 混进分类，避免说明性文字造成假阳性）。
- 注释层单独统计（§1.4），因为注释里确实有"必须/不得"等自由文本。
- 全量属性清单落盘为 TSV，可逐行核对。

### 1.4 注释层核查（防止"只查 label 漏判"）

`rdfs:comment` 251 条 + `skos:definition` 153 条 = 404 条自由文本，关键词命中：

| 关键词 | 命中 | 说明 |
|---|---:|---|
| 必须 | 60 | 字段/建模说明，如"必须区分发生时间/记账时间/入库时间" |
| 应当 | 2 | 同上 |
| 不得 | 6 | 同上 |
| 禁止 | 1 | 同上 |
| 期限 | 7 | 描述字段含义，如"协议期限" |
| 保留 / 留存 | 14 / 6 | 与 G05 唯一沾边的是 `attritionDate` 的"监管要求客户信息留存"，**没有任何期限数值** |
| 处置 / 流程 | 6 / 4 | `SalvageRecord` 的"由保险人处置（拍卖、拆解）"；`M-FIN-BANK-036` 的不良处置率口径。**都不是抵押物重估处置流程** |

| **重估** | **0** | 全图零命中 |

结论：注释里存在"规则腔"的句子，但都是**自由文本、不可机读、无主体/无时限/无阈值**；不能当作知识供给。

### 3.2 待人工输入（明确补不了的部分）

以下内容**不得由工程侧自拟**，必须由业务/制度 owner 给值、给文号、给条款：

- **G05 / KG-01**：保留期限的具体月数或年数；起算时点（关系终止日 / 合同到期日 / 销户日）；例外情形（诉讼、监管调查、争议未结是否延长）；到期处置方式（删除 / 匿名化 / 转归档）；依据文件与条款号。
- **G06 / KG-02、KG-03**：触发阈值（跌幅百分比或绝对值）；评估频率；处置步骤的顺序与名称（重新评估 / 追加担保 / 提前收回 / 处置抵押物）；每步时限；审批角色与权限；依据文件与条款号。
- **KG-04**：复评周期与"逾期未复评"的后果认定。
- **KG-06**：具体限额数值与适用口径（是否分行业、分客户类型）。
- **所有条目**：责任部门/岗位。

判断标准：**凡是要靠人（业务确认、制度文件）才能定的知识，一律列"待人工输入"；seed 里只留槽位，不填合理值。**

## 5. B 线最值得先补的三类知识

1. **时效类（保留期限 / 复评周期）**——最便宜。一个数值 + 一个起算点 + 一条依据，业务通常能直接确认；直接对应 G05，并可复用到"留存期/复评/数据保存"一批问法。**先做 KG-01、KG-04。**
2. **阈值类（限额 / 触发阈值）**——杠杆最高。它和 A 线的 85 条指标口径同源（集中度、大额风险暴露、押品覆盖率），补进去既能救指标类问法，也能给 A 的出数口径提供"限额"上下文；不需要新增实体，只需给已有指标挂约束。**先做 KG-03、KG-06。**
3. **流程类（处置流程）**——价值大但最贵。需要行内制度 + 业务确认，且步骤/时限/角色缺一不可；`01` 的骨架可以先立，值必须等人工。**KG-02 先立骨架、不填值；KG-05 后排。**

不建议优先做"政策约束"（KG-07）：范围最宽、最依赖制度文件、且难以验证完整性。

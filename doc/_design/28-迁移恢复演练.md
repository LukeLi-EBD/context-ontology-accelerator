## 11. 阻断项 B1 修复：附件原文进 bundle（2026-11-06）

### 11.1 修复前

| 项 | 修复前 |
| --- | --- |
| `blobs/` | 只导出 fs 侧 CAS 文件（17 个），不读 PG `blob_bytea`（3132 个） |
| `meta/blobs.jsonl` | 不存在，导入不知道 blob 属于谁 |
| `import-bundle` | 完全不消费 `blobs/` |

| drill 的 `smoke-s2` | **16/17**，唯一失败 `get.source` |

### 11.2 修复内容

- `export-bundle --include-blobs`：导出全部 `state='committed'` 的 blob（fs + PG bytea 两层），
  写 `blobs/<aa>/<sha256>` 与 `meta/blobs.jsonl`（hash/size/mime/tier/原 refs）；任一 payload
  读不到直接 `E_BUNDLE_BLOB_MISSING`，不产出半包。
- `verify_bundle`：新增 blob 清单交叉校验（清单条数/总字节/refs、文件大小、文件名=sha256）。
- `import-bundle`：先校验再写 CAS（tmp→fsync→同卷 rename），已存在则重新校验后跳过；
  全部通过才写 `platform.blob` + `blob_ref`，任一不符整批失败并删除本次新写入文件。
  新增 `--dry-run`（只统计 `toWrite/existing/missing/conflicts`，不落盘不建库）。
- `drill-migrate.ps1`：导出固定加 `--include-blobs`，比对增加 `blob` 与 `blob_bytes` 两项；
  目标配置在起栈后从源栈 `platform.yaml` 复制，避免 `CHANGE_ME` 认证失败。

### 11.3 修复后实测

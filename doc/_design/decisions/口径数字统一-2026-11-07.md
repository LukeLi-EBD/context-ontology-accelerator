## 3 为什么这么改

1. **以 8080 为唯一基准实例**：它是唯一同时具备 schema 42、完整合成 A-Box、全量文档与观测的生产形态栈；8082 只有 55 条指标有观测、文档 39 篇，会算出第三套数字；8087 已下线，其 74 / 62 / 12 只能作为互证。
2. **三分口径不许混用**：结构可算 74 是**定义级**（`computability_tier`），有观测 57 是**数据级**（`distinct metric_id`），对外可出数 42 是**运行时判定**（manifest `publishable && executable`）。三者回答不同问题，必须分行写。
3. **42 的边界必须同时写**：42 条全部依赖 `synthetic` 观测、0 条业务数据；只写 42 会让人误以为业务可出数。
4. **62 与 57 不是矛盾**：62 是结构可算数值指标（74 − 12 rule_set，定义级）；57 是 8080 当前有观测的指标数；独立栈因补水多 5 条观测达到 62。文档中"57→62"已注明是 8085 克隆栈结果，8080 现场仍 57。
5. **对外候选只保留可复算结构**：`externalEligible = regulatory ∧ publishable ∧ structurally_computable`，35 条逐条可证为 28 compute + 7 rule_set + 0 不可计算。

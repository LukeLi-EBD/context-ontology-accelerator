### 1.1 数据快照 id 算法（临时口径）

```
data_snapshot_id = "snap-counts-" + sha256(
    "docs=3066;chunks=15218;obs=37477;definitions=85;facts=10146"
)[:12]
                = snap-counts-489c77aa4d56
```

- 包含 `document`、`document_chunk`、`metric_observation`、`metric_definition`、`fact_event` 五项计数。
- **不包含**图存储三元组与 A-Box 推断数（需跨图存储读取）；这两项另列于 §2，不参与 id。
- 该 id 只能证明“数据面计数一致”，**不能恢复数据**。真正的 L4 需要 `pg_dump` + 图导出 + 校验和，尚未建立。
- 计数漂移即 id 漂移；`stack verify` 会同时比对计数与 id。

## 3. 可映射口径

### 3.1 定义

一列只有同时满足以下条件才算“可映射”：

1. 本体 T-Box 中存在一个**字面值属性**（datatype / identifier property），其业务含义与该列 1:1；
2. 该列值可直接落到该属性，不需要额外实体上下文或另一列补全；
3. 映射有明确依据（显式声明、归一化同名，或逐表语义候选）。

明确**不计入**可映射：

- **数值度量列**：本体用 `Metric` 节点表达度量，需要 `metricValue` + `metricType` 两列/上下文；单列 `balance`、`amount` 只绑定 `metricValue` 会丢失指标身份，属于假精确。
- **对象属性列**：`hasStatus`、`hasCurrency`、`productOf`、`channelOf` 指向实体，散表里的 `status`、`currency`、`channel` 只是代码，没有实体就无法绑定。
- **本地代理键**：`case_id`、`snapshot_id`、`txn_id` 等没有同名属性；`sourceRecordId` 是泛化来源记录号，不做逐列绑定。
- **逾期天数**：本体无 `daysPastDue` / `overdueDays`，`dpd`、`dpd_start`、`dpd_end`、`overdue_days`、`other_facility_dpd_90plus` 一律保留未绑定。
- **布尔标记**与**枚举/分类码**：没有对应的字面值属性。

代码位置：`platform/src/platform_core/catalog.py` 的 `MAPPABLE_BY_COLUMN_NAME`、`MAPPABLE_PAIRS`、`MAPPABLE_CANDIDATES`、`is_mappable()`、`binding_coverage()`。

## 5. 人工绑定入口

端点（G6 区块，追加在 `api.py` 末尾）：

```
POST /catalog/dictionaries/bind
{
  "table": "bank_loan_account",
  "column": "period_start",
  "propertyIri": "https://w3id.org/fsldm/core#validFrom",
  "operator": "data-ops",
  "basis": "期初观察日按 validFrom 登记",
  "note": "O-01 人工确认"
}
```

写入规则：

- `operator`、`basis` 必填；`propertyIri` 必须是已发布 T-Box 属性（静态 T-Box + 当前图合并校验），否则返回 `E_DICT_BINDING_INVALID`。
- 目标表/列必须已在字典中，否则返回 `E_DICT_COLUMN_NOT_FOUND`。
- 写入 `binding_method='manual'`、`confidence=1.0`，并把操作者/依据/时间/备注写入 `binding_note` 的 JSON：
  `{"audit":"manual","operator":"…","basis":"…","at":"…","note":"…"}`
- 行响应会解析出 `manualOperator`、`manualBasis`、`manualAt`、`manualNote`，便于展示与审计。
- `refresh` 遇到 `manual` 行时只更新物理元数据（类型/可空/注释/来源），**不会覆盖绑定与审计信息**。
- 只写字典绑定：不写图、不影响发布门禁、不作为本体权威；本体权威仍是已发布 T-Box。
- 不需要新增迁移（操作者/依据/时间复用 `binding_note` 与 `observed_at`），因此不占用 V39。

## 9. 复现核对

```sql
-- 逐表物理列 vs 字典行（28 张事实表）
SELECT c.table_name, count(*) AS physical_columns
FROM information_schema.columns c
WHERE c.table_schema='platform'
  AND c.table_name IN ('bank_collection_case','bank_collection_recovery', …)
GROUP BY 1 ORDER BY 1;

-- 字典总数与绑定档位
SELECT count(*),
       count(*) FILTER (WHERE binding_method='explicit')  AS explicit,
       count(*) FILTER (WHERE binding_method='name_match') AS name_match,
       count(*) FILTER (WHERE binding_method='manual')     AS manual,
       count(*) FILTER (WHERE binding_method='none')       AS none
FROM platform.data_dictionary;
```

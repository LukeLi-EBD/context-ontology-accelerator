## 3. Q8-c 双跑结果（原始输出，2026-11-06）

环境：`agent-platform-api` 容器内执行；Fuseki `agent-fuseki:0.1-s5`（`docker compose --profile graph-fuseki up -d fuseki`，默认不启）。

### 3.1 GraphStore：oxigraph-http vs jena-fuseki（同一用例，逐项比对）

命令：
```
docker compose exec -T -e PYTHONPATH=/app/src platform \
  python /tmp/hosttests/test_q8_dualrun.py
```

| 项 | 实现 A（oxigraph-http） | 实现 B（jena-fuseki） | 等价 | 差异说明 |
|---|---|---|---|---|
| `replace_graph` 写入三元组数 | 2 | 2 | yes | — |
| `count_graph`（replace 后） | 2 | 2 | yes | — |
| `ask` | true | true | yes | — |
| `query`（SELECT 行集合） | 2 行（`s1\x60one`、`s2\x60two`） | 同 | yes | — |
| `update`（INSERT DATA 后 count） | 3 | 3 | yes | — |
| `export_graph`（N-Triples 行数） | 3 | 3 | yes | GSP GET 与 SPARQL 导出字节等价 |
| `clear_graph`（后 count） | 0 | 0 | yes | Oxigraph 用 `CLEAR GRAPH`；Fuseki 用 `DROP SILENT GRAPH` |
| `probe` | true | true | yes | 写入→读回→清理 |

结论：**7 项契约方法 + probe 全部 yes**；`SERVICE` 在两端同样被拒绝（各自 `E_SPARQL_SERVICE`）；命名图白名单两端同样生效（`urn:platform:` 前缀）。

### 3.2 ReasoningService：ROBOT+ELK vs ROBOT+HermiT

| 用例 | 实现 A（robot/ELK） | 实现 B（robot/HermiT） | 等价 | 差异说明 |
|---|---|---|---|---|
| 一致图（`A⊑B⊑C` + `y∈A`） | `consistent=True`，code=`null` | `consistent=True`，code=`null` | yes | — |
| 不一致图（`A owl:disjointWith B` + `x∈A∩B`） | `consistent=False`，code=`null` | `consistent=False`，code=`E_ONTOLOGY_INCONSISTENT` | **partial** | 状态一致；ELK 路径不返回 `reasonCode`，HermiT 返回稳定错误码 |
| `classify`（HermiT） | — | `subClassOf=2`、`equivalent=0`、`disjoint=0` | 仅 B 侧 | ROBOT 对 `owl:Nothing` 的平凡 disjoint 公理已在 adapter 过滤 |

结论：一致性**状态等价**（yes），**错误码 partial**；`classify` 只在 HermiT 侧提供，不作为 ELK 等价项。

## 4. 关键取舍与限制

1. **Fuseki 只实现共同子集**：`query` / `ask` / `update` / `clear_graph` / `replace_graph` / `export_graph` / `probe`（另含 `count_graph`、`load` 的薄包装）。`construct`、`dump` 显式 `Unsupported`，不冒充。
2. **GSP 路径**：Fuseki 的 `replace_graph` 走 GSP `PUT /ds/data?graph=`；Oxigraph 走 SPARQL/其 HTTP API。两端语义（整图替换、原子性）在本用例中等价。
3. **命名图白名单**：两端按 `urn:platform:` 前缀收口，未做跨版本硬拒（见 05 §2.4 的取舍说明）。
4. **HermiT 只做一致性与分类**：`materialize` 仍走 ROBOT/ELK（`engine=hermit` 时只替换一致性门禁）；避免同一份物化在两个推理器间摇摆。
5. **默认路径不变**：默认仍是 `oxigraph-http` + `robot/ELK` + `fs` 大对象；Fuseki profile 默认不启，`graph.provider` 需显式改为 `fuseki` 且 endpoint 指向 `http://fuseki:3030`。
6. **未做**：Silo、Cache 实现、pyoxigraph 进程内（继续记 OQ-70/74/79/80 等）。

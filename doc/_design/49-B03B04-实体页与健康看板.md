## 2. B-03 实体页

页面：`/ui/entity.html?iri=<IRI>`（`entity.js`）
数据端点：`GET /ui/api/entity?iri=<IRI>&limit=<1..200>`

返回内容：

| 区块 | 说明 |
| --- | --- |
| `classes[]` | 类 IRI/标签、父类链 `chain[]`、该类实例数 `instanceCount`、`inferredOnly` |
| `requiredProperties[]` | 类及父类上 `owl:minCardinality` / `owl:minQualifiedCardinality` 约束，属性值、`valueCount`、`satisfied` |
| `properties[]` | 实体断言/推理属性取值 |
| `neighbors` | 邻居节点与边（同一三元组查询，边上限 200，标记 `truncated`） |
| `instanceCount` | 首个类在 A-Box 命名图中的实例数 |
| `relatedMetrics` | 按 `metric_field_binding` 反查：类名 → `entity_column` / `grain` 弱匹配；无命中时 `status=unbound` 并给出原因，不伪造链接 |
| `sources[]` | `sourceRef` 解析结果：`resolveUrl`、`href`（fact → `/browse/facts?table=...`，doc → `/source/resolve?ref=...`）、原文片段 |
| `evidenceBadge` | 后端统一判定，前端只渲染 |

### 徽标三态（后端唯一判定源）

| state | 含义 | 判定 |
| --- | --- | --- |
| `evidenced` | 有原文/事实 | 实体自身断言三元组存在 `rdfs:seeAlso` / PROV 溯源，或 PROV 图中 `prov:used` 关联到 `sourceRef` 且可解析 |
| `inferred` | 推测 | 仅有推理图三元组、断言图为空；`basis` 给出推理图、profile、推理作业，`judge` 为 `system:reasoning/<profile>` |
| `no-source` | 无依据 | 有断言三元组但找不到 sourceRef/PROV 链接；或该 IRI 无任何三元组（后者返回 404 `E_ENTITY_NOT_FOUND`） |

实例数、邻居、类归属均通过只读端点内部 SPARQL 查询，前端不拼 SPARQL。

入口：只读浏览实例列表 IRI、本体浏览实体搜索均可跳转实体页。

## 3. B-04 健康看板

页面：`/ui/health.html`（`health.js`）
数据端点：`GET /health/dashboard`（一次聚合返回）

字段：

- `coverage.classes`：总类数、有实例类数、覆盖率、无标签类数；
- `coverage.properties`：总属性数、有取值属性数、覆盖率；
- `coverage.instances`：A-Box 实例总数与命名图列表；
- `orphanInstances`：无出边（除 `rdf:type`/`rdfs:label`）且无入边的实例数；
- `shaclViolations`：取 `platform.ontology_import` 最新导入的 `violation_count`（标注采样时间，非实时重跑；无记录返回 `null`，不以 0 代替）；
- `inferenceFailures`：`platform.reasoning_job` 中 `kind=materialize AND state=failed` 计数 + 最近作业；
- `migration`：`platform.schema_version MAX(version)` vs `SUPPORTED_SCHEMA_VERSION`；
- `readyz`：复用 `/readyz` 的 database / graph / storage 判定；
- `tbox`：`tbox/current` 指针（versionId、semver、graph）；
- `dataSource`：端点清单、采样时间与“不返回猜测值”说明。

每个区块带 `source` 字段；查询失败时数值为 `null` 且带 `error`，页面显示“不可算”。

### 本体 diff

`GET /health/ontology-diff?from=<ver>&to=<ver>`

- 无参：`to=tbox/current`，`from` 为版本列表中的上一版（跳过 deprecated）；
- 返回 `counts`（added/removed triples、classes、properties）与 `examples`（每类最多 5 条，三元组示例用图 `MINUS` 查询）；
- 错误码：
  - `E_DIFF_VERSION_NOT_FOUND`（404）：`from`/`to` 版本不存在或无图；
  - `E_DIFF_NO_CURRENT`（409）：无参且无 `tbox/current`；
  - `E_DIFF_NO_PREVIOUS_BASELINE`（409）：当前版本无上一版；
  - 非 GET 请求由 FastAPI 返回 405。

## 2. 配置与 Q8 分码

```yaml
terms:
  gate: warn                     # off | warn | block
  blocking_codes:                # 严重级别阈值；不在列表内的问题码一律 warning
    - SURFACE_SHARED_BY_MULTIPLE_CONCEPTS
    - PREF_CONFLICTS_WITH_ALT_OF_OTHER_CONCEPT
    - CONCEPT_MISSING_PREF_LABEL
    - SUPPRESSED_SURFACE_STILL_ALIAS
    - ALIAS_INCOMPLETE
    - ALIAS_TARGET_MISSING
    - GUARD_REGEX_INVALID
  coverage_decrease_tolerance: 0 # 相对上一发布版本，覆盖率下降超过该值记 warning
```

环境变量写法：`PLATFORM__TERMS__GATE=block`。

| 输入 | 结果 |
|---|---|
| `off` / `warn` / `block` | 接受，三档均已实现（`TERMS_GATE_IMPLEMENTED`） |
| 其他任意值 | `E_PROVIDER_INVALID`，`key=terms.gate` |
| 未来某值被列入 `TERMS_GATE_KNOWN` 但不在 `TERMS_GATE_IMPLEMENTED` | `E_PROVIDER_NOT_IMPLEMENTED`，`key=terms.gate` |

## 3. 三档语义

| 档位 | 是否执行核对 | 发布 | 响应 | 证据包 |
|---|---|---|---|---|
| `off` | **不执行**（`evaluate_content` 不被调用） | 与接入前一致 | 不新增任何 `terms` 键 | 不含 `gates.terms` |
| `warn` | 执行 | **不拦截** | 顶层 `termsGate` + `gates.terms` | `gates.terms` 写入 `platform.ontology_evidence` |
| `block` | 执行 | 存在 blocking 级问题时 **拒绝**（409） | 成功时同上；拒绝时为 `E_TERM_GATE_BLOCKED` | 拒绝时 **不写任何行**（见 §7） |

`termsGate` 字段：

```json
{
  "gate": "warn",
  "verdict": "pass|warned|blocked",
  "blocked": false,
  "enforced": false,
  "blocking": 0,
  "warnings": 0,
  "total": 0,
  "blockingCodes": ["..."],
  "coverageDecreaseTolerance": 0.0,
  "coverage": {"actual": {}, "baseline": {}, "declines": []},
  "findings": [],
  "importId": "imp-...",
  "versionId": "ont-...",
  "dryRun": true,
  "checkedAt": "...",
  "readOnly": true
}
```

- `warn` 档即使 `blocking > 0` 也返回 `blocked=false`、`verdict=warned`。
- `block` 档只有 blocking 码命中才 `blocked=true`；纯 warning（定义/notation 缺口、覆盖率下降）不拦截，`verdict=warned`。
- `dryRun=true` 时照常返回门禁结果，但不会因 block 拒绝（没有发布动作）。

## 4. 严重级别映射

| 问题码 | termgov 默认 | 门禁默认 | 说明 |
|---|---|---|---|
| `SURFACE_SHARED_BY_MULTIPLE_CONCEPTS` | blocking | **blocking** | 同一 surface 指向多个概念 |
| `PREF_CONFLICTS_WITH_ALT_OF_OTHER_CONCEPT` | blocking | **blocking** | pref/alt 冲突 |
| `CONCEPT_MISSING_PREF_LABEL` | blocking | **blocking** | 概念无 prefLabel |
| `SUPPRESSED_SURFACE_STILL_ALIAS` | blocking | **blocking** | suppressed 表面仍是 altLabel |
| `ALIAS_INCOMPLETE` | blocking | **blocking** | TermEntry 缺 label/forClass |
| `ALIAS_TARGET_MISSING` | warning | **blocking**（本任务提升） | alias 指向未导入概念/类 |
| `GUARD_REGEX_INVALID` | blocking | **blocking** | guard 正则无法编译 |
| `CONCEPT_MISSING_DEFINITION` | warning | warning | 纯覆盖率缺口 |
| `CONCEPT_MISSING_NOTATION` | warning | warning | 纯覆盖率缺口 |
| `ALIAS_LABEL_DUPLICATED` | warning | warning | 同一别名重复登记 |
| `TERM_COVERAGE_DECREASE` | —（门禁生成） | warning | 相对当前 T-Box 覆盖率下降 |

`blockingCodes` 可把任意 warning 提升为 blocking（单测 `test_5_severity_threshold_is_reconfigurable`），也可把默认 blocking 降级。每个 finding 同时保留 `defaultBlocking`（termgov 原判定）与 `severity`（门禁判定），便于解释差异。

覆盖率下降按四项比例比较：`conceptPrefCoverage`、`conceptDefinitionCoverage`、`conceptNotationCoverage`、`aliasTargetCoverage`；任一项下降幅度超过 `coverageDecreaseTolerance` 即记一条 warning。基线来自当前 `tbox/current`；无指针或无对应比例时跳过，不填 0。

## 10. 已知边界

1. 门禁挂在 `/ontology/imports/{id}/publish`（`publish_import`）路径；直接调用 `OntologyRegistry.publish` 的 bootstrap/legacy 路径不带术语门禁。
2. 未调用 `set_terms_gate` 的 registry 视为不做门禁（等价 off），用于兼容既有脚本与单测；装配路径 `assembly.py` 会注入 `cfg.terms`，因此正常服务默认 warn。
3. block 拒绝不写证据包，这是为了满足“绝不部分落库”；审计证据是 409 错误体（问题清单 + allowed）与请求日志。成功/warn 的审计记录在 `ontology_evidence`。
4. `dryRun` 只报告不拒绝；真正拒绝仅发生在非 dry-run 的实际发布。
5. 覆盖率下降是“相对当前发布版本”的比例比较，不比较概念绝对数；基线不可读时不做下降判断。

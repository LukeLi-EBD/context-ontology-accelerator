## 3. 接口

- `GET /metrics/{metric_id}/compute`
  - 参数：`asOf`（即时口径）或 `periodStart`+`periodEnd`（期间口径）；`dataSource` 默认 `fixture`；`internal` 默认 `false`。
  - 返回：`metricId / metricKind / windowKind / window / dataSource / rows / rowCount / computedAt`。
  - 不可算时返回稳定 provider code + 原因，不返回 0 或空结果冒充可算。
- 以上路由全部位于 `api.py` 末尾 `# --- G2 metrics-core routes ---` … `# --- end G2 ---` 区块内。

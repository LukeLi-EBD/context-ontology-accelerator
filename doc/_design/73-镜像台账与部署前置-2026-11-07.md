## 3. 部署前置与教训

### 3.1 判断运行版本的唯一依据

**镜像 tag 可被 re-tag 顶掉，判断运行版本必须看容器 image id，不能看 tag。**

本次 tag 漂移事实：

- 12:12，`agent-platform:merged-r02` 被 `sha256:5ac981053ee5`（docker commit 临时件）顶掉；
- 8082 容器自 10:46 起一直运行 `sha256:adf44d206356`（容器 image id 固定，不受 tag 变更影响）；
- 12:27 后 `merged-r02` 已修正回 `sha256:adf44d206356`。

核验命令：

```powershell
docker inspect <container> --format "{{.Config.Image}} {{.Image}} {{.State.StartedAt}}"
```

### 3.2 换镜像前置检查

1. 构建镜像必须用仓库 `Dockerfile` 从目标提交干净构建，禁止 `docker commit` 产物入库。
2. 换栈前核对镜像 `SUPPORTED_SCHEMA_VERSION` 与目标库 `MAX(platform.schema_version)` 一致；不一致不得替换。
3. 替换前记录回退锚点：旧镜像 tag + image id、容器 id、启动时间（见 `_tmp/anchor-8082.txt` 历史段落）。
4. 启动日志必须确认 `migration applied, "to": []`，即未实际执行迁移。
5. 换后复核业务表行数与 `graph_pointer` 未变。

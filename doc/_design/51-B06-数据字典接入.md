# 51 · B-06 数据字典接入

> 状态：已完成（2026-11-06）
> 产出：`platform.data_dictionary`（V31，375 行 / 28 张事实表）、`platform_core/catalog.py`、三个字典端点、`/browse` 数据字典 tab、13 条单测
> 边界：字典只读、只作浏览与对账用途；`property_iri` 是绑定提示，不参与发布门禁，不作本体权威

## 1. 目标与边界

把 28 张事实表（375 列）的物理元数据登记为字典行，并逐列给出“本体属性绑定提示”，让列名、类型、注释、绑定关系可在 `/browse` 页面直接查看。

- 内省只读：PostgreSQL 读 `information_schema.columns` + `pg_description`；不写事实表、不改本体。
- 绑定三档：`explicit`（人工显式）→ `name_match`（名称归一化）→ `none`（保留原因）。
- 字典不是发布门禁输入，也不是本体权威：不因绑定缺失阻断任何发布流程。
- MySQL / Glue 无可用源时**显式报错**，不伪造结果。

## 2. 迁移 V31

`platform/src/platform_core/sql/V31__data_dictionary.sql`，`SUPPORTED_SCHEMA_VERSION` 30 → 31。

| 列 | 说明 |
| --- | --- |
| `catalog_name / schema_name / table_name / column_name` | 联合主键（四元组） |
| `data_type / is_nullable / comment` | 物理元数据（注释来自 `pg_description`） |
| `source_kind` | `pg` / `mysql` / `glue`（CHECK） |
| `property_iri` | 绑定属性 IRI，可空 |
| `binding_method` | `explicit` / `name_match` / `manual` / `none`（CHECK） |
| `confidence` | `numeric(4,3)`，显式 1.0/0.9，名称匹配 0.8，未绑定 NULL |
| `binding_note` | 未绑定原因 / 显式依据说明 |
| `observed_at` | 最近一次实际变化时间（未变化不刷新） |

可重入：`CREATE TABLE IF NOT EXISTS` + 每列 `ADD COLUMN IF NOT EXISTS`，重复执行不丢数据。

## 3. 内省

| 源 | 实现 | 实测 |
| --- | --- | --- |
| `pg` | `information_schema.columns` 关联 `pg_class/pg_attribute/pg_description`，按表、列序返回类型/可空/注释 | 28 表 375 列，92 列有注释 |
| `mysql` | 代码路径已实现 `information_schema.columns` + `pymysql`；未配置 DSN 或驱动缺失时抛 `E_DICT_SOURCE_UNREACHABLE` | 本机无 MySQL → 503 `E_DICT_SOURCE_UNREACHABLE`（`sourceKind=mysql`） |
| `glue` | 只走注入的目录适配器；未配置时同错误码 | 503 `E_DICT_SOURCE_UNREACHABLE`（`sourceKind=glue`） |

刷新时读取当前已发布 T-Box 的属性索引（`ontologyVersion` 随响应返回）；图不可达时退回静态镜像（`ont-11f92ebb3326` 的 129 属性），绑定结果仍可复现。

## 4. 列 ↔ 属性绑定

规则：先查显式表（表级优先于 `("*", column)` 通配），再按“去下划线 + 小写”归一化匹配属性 local，最后落 `none` 并写明原因。

| 档位 | 数量 | 说明 |
| --- | --- | --- |
| `explicit` | 26 | 客户号→`core#partyId`（14）、保单号→`core#agreementId`（4，0.9）、放款日/首期还款日、额度生效起止、保单签发日、核保统计起止等（8） |
| `name_match` | 10 | `agreement_id`、`asset_id`、`due_date`、`event_id`、`event_type`、`maturity_date`，confidence 0.8 |
| `manual` | 0 | 预留人工覆盖，本轮无 |
| `none` | 339 | 每行带 `binding_note` |
| 合计 | 375 | 28 张事实表 |

未绑定原因分类：

- **本体确实无对应属性**：`dpd / dpd_start / dpd_end / overdue_days` → 注记“本体 T-Box 无逾期天数属性（无 daysPastDue/overdueDays），不臆造绑定”。任务示例 `bank_loan_account.dpd` 在该表并不存在（实际列是 `dpd_start/dpd_end`），`dpd` 位于 `bank_ews_signal`；两处均按未绑定处理并在文档留痕。
- `account_id` → 本体无 `accountId` 属性，按本地业务编号保留；
- `*_id / *_no / *_key` → 事实表本地编号；
- `data_source / fixture / created_at` → 系统审计列；
- `as_of` → 本体仅有 `observationDate`，名称不相等，未自动绑定；
- 其余 → “名称未命中本体属性（归一化 xxx）”。

## 5. 接口与页面

| 端点 | 行为 |
| --- | --- |
| `GET /catalog/dictionaries` | 分页 + 过滤（`catalog/schema/table/column/sourceKind/bindingMethod/q`，`limit/offset`），返回 `items/count/total` |
| `GET /catalog/dictionaries/{table}` | 单表全列 + 三档计数 + 来源集合 + `observedAt` |
| `POST /catalog/dictionaries/refresh` | 只读内省 + upsert，返回 `processed/inserted/updated/unchanged/bySourceKind/binding`；重放不增行、未变化不刷新 `observed_at` |

`/browse` 新增“数据字典”tab：表/列/类型/可空/注释/来源/绑定方法/绑定属性/confidence/说明，支持表名、列名、来源、绑定档位过滤与分页；提供“刷新字典”按钮。

实测（本机镜像）：

- `GET /catalog/dictionaries?limit=3` → `total=375`；
- `?table=bank_loan_account&bindingMethod=none&limit=5` → 过滤生效；
- `GET /catalog/dictionaries/bank_loan_account` → 26 列：`explicit=3`、`name_match=1`、`none=22`；
- 首次 refresh `inserted=375`；重放 `inserted=0 / updated=0 / unchanged=375`；
- 页面：数据字典 tab 实测显示“共 375 行”，`customer_no` 行展示 `explicit` 与 `core#partyId`。

失败码：无表 `GET /catalog/dictionaries/no_such_table` → 404 `E_DICT_TABLE_NOT_FOUND`；非法过滤值 → 400 `E_DICT_FILTER_INVALID`；未知来源 → 400 `E_DICT_SOURCE_UNKNOWN`。

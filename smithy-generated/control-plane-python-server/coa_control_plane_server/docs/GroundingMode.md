# GroundingMode

Grounding mode — how aggressively induced classes are aligned to existing ontologies. NONE disables grounding; STANDARD auto-grounds exact-name matches; ENHANCED (default) always defers to the LLM reranker for domain verification.

## Enum

* `NONE` (value: `'NONE'`)

* `STANDARD` (value: `'STANDARD'`)

* `ENHANCED` (value: `'ENHANCED'`)

# OntologyFileFormat

Serialization format of an ontology file, as accepted by IngestOntologyFromS3. Several spellings name the same format.

## Enum

* `TURTLE` (value: `'turtle'`)

* `TTL` (value: `'ttl'`)

* `RDF_MINUS_XML` (value: `'rdf-xml'`)

* `RDF_PLUS_XML` (value: `'rdf+xml'`)

* `OWL_MINUS_XML` (value: `'owl-xml'`)

* `XML` (value: `'xml'`)

* `JSON_MINUS_LD` (value: `'json-ld'`)

* `JSONLD` (value: `'jsonld'`)

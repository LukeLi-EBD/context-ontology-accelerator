# VkgHealthStatus

Health of the namespace's VKG translation service. HEALTHY: running and able to translate. UNAVAILABLE: exists but not serving. PROVISIONING: service is starting up (deployment in progress, not yet serving) — expected to become HEALTHY shortly. UNKNOWN: not deployed yet or state undetermined.

# ScanTrigger

What triggered a scan job. INITIAL is the first scan on connect; MANUAL is a user-initiated rescan; SCHEDULED and EVENT are automated rescans.

## Enum

* `INITIAL` (value: `'INITIAL'`)

* `MANUAL` (value: `'MANUAL'`)

* `SCHEDULED` (value: `'SCHEDULED'`)

* `EVENT` (value: `'EVENT'`)

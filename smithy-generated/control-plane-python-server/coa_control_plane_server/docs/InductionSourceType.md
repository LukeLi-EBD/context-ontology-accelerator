# InductionSourceType

Discriminator distinguishing structured (table-to-ontology) induction runs from unstructured (knowledge-graph-to-ontology) induction runs. Persisted as a top-level attribute on `OntologyProposals` and induction-job items so the steward review queue and list endpoints can filter by origin.

## Enum

* `STRUCTURED` (value: `'STRUCTURED'`)

* `UNSTRUCTURED` (value: `'UNSTRUCTURED'`)

* `BRIDGE` (value: `'BRIDGE'`)

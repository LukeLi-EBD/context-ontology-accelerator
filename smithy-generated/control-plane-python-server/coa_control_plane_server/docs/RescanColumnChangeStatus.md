# RescanColumnChangeStatus

How a re-scan changed a column, relative to the last approved scan. Wire values are lower-case to match what the diff has always emitted, so naming them here is not a breaking change.

## Enum

* `ADDED` (value: `'added'`)

* `REMOVED` (value: `'removed'`)

* `MODIFIED` (value: `'modified'`)

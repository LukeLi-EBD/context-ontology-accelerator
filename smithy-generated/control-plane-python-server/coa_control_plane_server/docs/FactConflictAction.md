# FactConflictAction

Adjudication applied to a conflict group. Wire values stay lowercase because the ledger and the console have used them since the first release; the model follows the wire rather than renaming it.

* `KEEP_BOTH` (value: `'keep_both'`)

* `MERGE` (value: `'merge'`)

* `BATCH` (value: `'batch'`)
